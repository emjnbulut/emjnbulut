# Hi, I'm Emin 👋

Computer engineering student at Uludağ University. I build free learning tools and teach electronics and English.

## What I'm working on

- **[ESP32 From Zero](https://github.com/emjnbulut/esp32-from-zero)** is a beginner video series on the ESP32 (C / Arduino). It has English narration, dubs in four languages and subtitles in 12. The channel is [Pin by Pin Lab](https://www.youtube.com/channel/UCOGFzocCfvfYWiA5-MfHHwQ).
- **[Pin by Pin Lab](https://github.com/emjnbulut/esp32-learning-lab)** is a free in-browser ESP32 simulator with projects that follow the course. [Try it live](https://emjnbulut.github.io/esp32-learning-lab/).
- **[Lantern English](https://lantern-english.github.io/)** teaches English through leveled stories, articles and videos, with a Turkish hint on every word.

## Tech
